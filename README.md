# Employee Filter System

A full-stack Employee Management and Filtering Dashboard built using Spring Boot, PostgreSQL, React, and Vite.

This project demonstrates real-world backend filtering using JPA Specifications and frontend integration with dynamic sidebar filters similar to e-commerce platforms.

---

# Features

## Backend Features

- REST APIs using Spring Boot
- PostgreSQL database integration
- Dynamic filtering using JPA Specifications
- Pagination support
- Sorting support
- Search functionality
- Layered architecture
- Production-style project structure

## Frontend Features

- React + Vite frontend
- Sidebar dropdown filters
- Search bar
- Dynamic employee table
- Backend API integration using Axios
- Responsive dashboard layout
- Amazon-style filter UI inspiration
